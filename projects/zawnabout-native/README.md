# zawnabout-native

The desktop host. Run it in a window to play, or with `--headless --script FILE --out DIR` to run a script and save screenshots. `--map FILE` writes a top-down map of the world. `--no-play` leaves gameplay off.

Keys, settings and the saved game live in `%APPDATA%/zawnabout` (`keys.txt`, `prefs.txt`, `save-a.txt`).
